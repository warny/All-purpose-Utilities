# omy.Utils.Parser.Antlr4.Common

Shared ANTLR4 import-composition contracts used by the `omy.Utils.Parser` runtime and its Roslyn generator. Most applications should reference [`omy.Utils.Parser`](../Utils.Parser/README.md) rather than this infrastructure package directly.

The parser package train uses synchronized `2.0.0-rc.1` versions. Release-candidate APIs can change before `2.0.0` and follow the repository's production support contract.

[Versioned API documentation](https://warny.github.io/All-purpose-Utilities/v2.0.0-rc.1/)
