# NTS-39 — the UK, BG, CS and SK fraction domains left closed by NTS-30H (2026-10-16)

Opened by NTS-30H. Starting master: `f94908f6` (NTS-30H, #644). Sources: `docs/NTS-08-linguistic-sources.md`, section
NTS-39 (each form marked attested, rule or inference).

## Architecture

No engine, XSD, XML model, option or public API change. `IFractionLanguageSpecifics` already gave what every new
reading needs: the plugin returns the denominator text (*třetin*, *lomeno dvaceti třemi*, *lomené číslom sto jeden*)
and the variants it forces on the numerator; the numerator stays in the cardinal pipeline. The work is inside
`SlavicAdjectivalOrdinalLanguageSpecifics.cs` (shared helpers, CS, SK, UK) and `BulgarianOrdinalLanguageSpecifics.cs`;
the four XML files only had their comments updated.

Shared helpers: `ClassifyFractionNumerator` loses its `Unsupported` class and takes one policy flag (a compound ending
in one reads as one: UK only); `TryBuildFractionNoun` takes the counting gender used with the genitive plural (CS
`standalone`, SK `mužský`); `InstrumentalBelowHundred` composes a 2–99 instrumental from a language's tables, with no
form for a final one.

## Review follow-up (PR #645)

The first version read every SK denominator from 100 without a noun as *lomené číslom* + cardinal (*dva lomené číslom
tristo šesťdesiatpäť*): the size of the number, not its structure, chose *číslom*. Slovenská reč 43 (1978) reads
*jeden lomené sto štyridsiatimi dvoma*, and Ondrus (1968) §8 sets the grammar of a compound by its last component.
`SlovakOrdinalLanguageSpecifics.InstrumentalCardinal` now declines the last component and keeps the words before it
absolute (*jedna lomené sto štyridsiatimi dvoma*, *dva lomené tristo šesťdesiatimi piatimi*, *jedna lomené tisíc
štyridsiatimi dvoma*); *číslom* stays for an indeclinable last component (*dvesto*, *tisíc sto*, *dvetisíc*,
*dvesto dvadsaťjeden*) and a bare final *jeden* (*sto jeden*). `IFractionLanguageSpecifics` is unchanged. The
numerator of one stays *jedna* (Ondrus); the 1978 *jeden* is recorded as a divergence in the sources. Only SK
fraction readings with a declinable last component from 100 change; NumberToString tests: 2 501 passed.
