# NTS-37 — Finnish large numbers, ordinals to 1 999 999, cases of zero (2026-10-15)

Opened by NTS-30E. Starting master: `bb9ea21b` (NTS-30E, #640).
Sources: `docs/NTS-08-linguistic-sources.md`, section NTS-37.

## Root cause

- FI declared `maxNumber="999999"`: every value from a million threw `ArgumentOutOfRangeException`. Its single
  suffix `miljoona` was dormant configuration, and inheriting the generic long scale would have produced *biljardi*,
  *triljardi*, which Finnish does not use (Kielitoimiston sanakirja: *biljardi* is the cue game; fi.wikipedia: "eivät
  ole normien mukaisia"). 10^15 is *tuhat biljoonaa*: the multiplier of *biljoona* spans six digits, which neither
  the uniform groups nor `groupPattern` can express.
- The ordinals from 2000 failed closed for lack of a source; 1001–1999 were soldered (`tuhannesensimmäinen`) whereas
  Kielitoimiston ohjepankki separates the groups (*3 760. kolmastuhannes seitsemässadaskuudeskymmenes*).
- *nolla* kept its nominative in every case (dictionary: *nollan*, *nollaa*).

## Generic primitive — `pairedScalesFrom`

`<NumberScale pairedScalesFrom="n">` / `NumberScale.PairedScalesFrom` (`int?`, `init`, ≥ 1, default `null`):

- from scale `n` on, only `n`, `n + 2` … are named; the multiplier of a named scale covers its group and the one
  above, and is rendered as a complete cardinal (recursive conversion with the caller's variants: its own groups,
  junctions, elisions and agreement);
- the upper scales (`n + 1`, `n + 3` …) have no name: `GetScaleName` throws `InvalidOperationException`; the
  `maxNumber` validation, the `<GeneratedScaleForm>` probe (multipliers up to 10^6 − 1, capped by the existing probe
  limit) and the suffix-reachability check skip them;
- `baseOn`: absent inherits, explicit replaces (presence tracked by `PairedScalesFromSpecified` on the internal-use
  `NumberScaleXmlModel`).
- Public model `NumberScaleType.PairedScalesFrom` (`int`, 0 = no pairing, like `StartIndex`), with no `…Specified`
  companion (audit rule pinned by `PublicApi_XmlSpecified_NotPublic_NumberScaleType`, which caught the first draft);
  `ShouldSerializePairedScalesFrom()` leaves the default 0 out, since the XSD declares a positive integer.

Public API additions (ApiCompat against `bb9ea21b`: no breaking change; strict mode lists only the 9 additions):
`NumberScale.PairedScalesFrom`, `NumberScaleType.PairedScalesFrom` and `ShouldSerializePairedScalesFrom()`,
`NumberScaleXmlModel.PairedScalesFrom` / `PairedScalesFromSpecified`. Chosen over a Finnish-specific rule because ES/EU have the same structure
(*mil millones*, NTS-30): the primitive is reusable there.

## Finnish configuration

- `baseOn="SCALE-LONG"`, `maxNumber` removed; suffixes `joona`, `jardi` with `suffixSeparator="l"`;
  `pairedScalesFrom="4"`; all four Conway tables in Finnish spelling (*kvadri*, *kvinti*, *seksti*, *okti*, *noni*,
  *(n)desi*, *(n,ks,s)senti* …).
- `<GeneratedScaleForm>` *joona*/*joonaa* and *jardi*/*jardia*; the multiplier one is dropped by a `groupWithScale`
  trigger `^yksi (?=\S+$)` (a `ReplacementRule` cannot have an empty new value), which keeps *kaksikymmentäyksi
  miljoonaa* and *tuhat yksi biljoonaa*.
- Cases: the NTS-30E `Anywhere` rules generalized to the suffix fragments (*-joona*, *-jardi*), plus `Standalone`
  *nollaa* / *nollan*.
- Ordinals: ordered `Anywhere` ordinal replacements (every component → its ordinal; *yksi* → *yhdes*, *kaksi* →
  *kahdes* inside a larger number) replace the former word rules; compositions 1001–999 999 by 1000 and
  1 000 001–1 999 999 by 1 000 000 with separator `" "`; guard widened to the nominative of 0–1 999 999.

## Regression dump

negatives, `GetScaleName` 0–60, zero and million cardinals and ordinals under every variant), 1 731 042 lines:
**5 204 changed, all FI**. 3 200 were errors that now render; the ordinals that already rendered and changed are
exactly 1001–1999 (spacing); the five lines still failing only change exception type (`MathematicalFraction` reading,
unsupported in Finnish, now reached instead of the domain error). Clock (`K`) and times (`T`) byte-identical; no
other culture changes.
