# NTS-46 — NTS-42 E/UK and F/UK: Ukrainian zero and generated-scale fractions (2026-10-21)

Starting master: `1e321c51` (NTS-45, #652; no commit since). The two Ukrainian closures NTS-42 kept after NTS-45,
treated in one change: E/UK (a zero numerator) and F/UK (oblique numerators from 10^12). No public API, no XSD, no
interface and no engine change; the internal `IScaleNounSource` of NTS-42 F (#651) is reused as is. Sources:
`docs/NTS-08-linguistic-sources.md`, section "NTS-46" (#1–#7 below refer to it).

| Family | Result |
|---|---|
| E/UK — Ukrainian zero numerator, every case | **closed** (opened) |
| F/UK — Ukrainian oblique numerators from 10^12 | **closed** (opened) |

NTS-42 itself stays open: D (CS/SK), E/CS, and the SK genitive singular of a generated *-ón* noun.

## E/UK — zero

**Sources and levels.**
- **Normative rule** — Правопис 2019 §107.1 (#1): fractions decline as ordinary numerals, the numerator as a cardinal,
  the denominator as an ordinal; §105 does not list *нуль* (#2).
- **Class rule** — ПНТУ 2015 (#3): "нуль, тисяча, мільйон, мільярд, трильйон, квадрильйон … відмінюються як іменники".
- **Attested paradigm** — VESUM *нуль* (#5): *нуль, нуля, нулеві / нулю, нуль, нулем, нулю / нулі / нулеві*.
- **Attested construction with zero** — ПНТУ 2015, p. 135 (#4): the case paradigm of *нуль цілих сім десятих* with the
  rule "Якщо десятковий дріб починається на нуль, то частина цілих не відмінюється" (*нулем цілих*, against *трьома
  цілими*).
- **Productive application** — *0/3*, *0/5*, *0/21*: no source quotes *нуля третіх* or *нулем третіх*.

**Construction.** *нуль* is a noun and, like *тисяча* and *мільйон*, governs the genitive plural of what it counts, which
then stays unchanged in every case (#4). The denominator after *нуль* is therefore the genitive plural in every case —
the rule the plugin already applied after a numerator ending in a scale noun (`numerator % 1000 == 0`, *тисячею
третіх*), which zero satisfies without a special case. The request suggested the denominator in the case (*нулем
третіми*); #4 contradicts it (*нулем цілих*, not *нулем цілими*), so it was not adopted.

**Forms of *нуль*.** The plugin keeps the first VESUM form of each cell (*мільйонові*, *мільйоні*, NTS-40): dative
*нулеві* (VESUM *нулеві, нулю*; #4 *нулю (нулеві)*, both normative), locative *нулю* (VESUM *нулю, нулі, нулеві*; #4
*на нулю (нулеві)*). One form per case; no new API exposes the variants.

| Case | 0/3 | 0/5 | 0/10 |
|---|---|---|---|
| називний | нуль третіх | нуль п'ятих | нуль десятих |
| родовий | нуля третіх | нуля п'ятих | нуля десятих |
| давальний | нулеві третіх | нулеві п'ятих | нулеві десятих |
| знахідний | нуль третіх | нуль п'ятих | нуль десятих |
| орудний | нулем третіх | нулем п'ятих | нулем десятих |
| місцевий | нулю третіх | нулю п'ятих | нулю десятих |

The caller's gender does not change these readings (*нуль* has its own gender; nothing is forced on it). In the
nominative the cardinal pipeline writes the zero (`zero="нуль"`); the oblique cases are spelled by the plugin
(`s_zeroCases`). Compound and soft/hard denominators follow the existing `PluralOrdinal`/`GenitivePlural`: *нулем
двадцять перших*, *нуля двадцять третіх*, *нулю тисячних*. A denominator of one stays closed.

## F/UK — generated scales from 10^12

**Architectural cause.** The Ukrainian builder still worked on `long` with three static noun tables, whereas the
converter has handed the CS and SK plugins its own scale nouns since NTS-42 F (`IScaleNounSource`).

**Change.** `UkrainianOrdinalLanguageSpecifics` implements the internal `IScaleNounFractionLanguageSpecifics`, exactly
as CS and SK: the public overload passes no noun source, the converter's overload passes its own. `DeclineCardinal` is
now `BigInteger` and walks `ThousandGroups`; `тисяча`, `мільйон`, `мільярд` stay static `ScaleNoun` records (unchanged
forms), every scale from 4 (10^12) is `ReadScaleNoun` of the base class. `AppendDeclinedScale` takes a `ScaleNoun` and
fails closed on a missing form. `MaxDeclinedNumerator` is gone. The plugin contains no generated name: the noun is
`ConwayPrefix + ль + suffix fragment`, built by the converter's own `BuildDynamicName`.

**Configuration.** The UK `<GeneratedScaleForm suffix="0">` receives the twelve case keys, read by key name
(`ScaleNounFormKeys`), so the Ukrainian case order (instrumental before locative, `FractionCaseOrder`) needs no new
permutation:

| key | form | key | form |
|---|---|---|---|
| `singular.nominative` | йон | `plural.nominative` | йони |
| `singular.genitive` | йона | `plural.genitive` | йонів |
| `singular.dative` | йонові | `plural.dative` | йонам |
| `singular.accusative` | йон | `plural.accusative` | йони |
| `singular.locative` | йоні | `plural.locative` | йонах |
| `singular.instrumental` | йоном | `plural.instrumental` | йонами |

`one`, `few`, `many` and `UkrainianPluralLexicalFormSelector` are unchanged; cardinals ignore the new keys.

**Levels.** *трильйон*, *квадрильйон*, *квінтильйон*: **attested paradigms** (#6, VESUM first forms *-ові*, *-і*, as
*мільйон*); same noun class: **class rule** (#3); higher Conway names: **productive application by morphological class**
(the prefix invariant, only the configured suffix inflected), as AGENTS.md allows for generated names.

**Readings** (exact strings pinned by `NumberToStringNts46Tests`):

| Numerator /3 | Case | Reading |
|---|---|---|
| 10^12 | родовий | одного трильйона третіх |
| 10^12 | давальний | одному трильйонові третіх |
| 10^12 | орудний | одним трильйоном третіх |
| 10^12 | місцевий | одному трильйоні третіх |
| 10^12 + 1 | орудний | одним трильйоном однією третьою |
| 2 × 10^12 | давальний | двом трильйонам третіх |
| 5 × 10^12 | орудний | п'ятьма трильйонами третіх |
| 21 × 10^12 | давальний | двадцяти одному трильйонові третіх |
| 22 × 10^12 | орудний | двадцятьма двома трильйонами третіх |
| 101 × 10^12 | родовий | ста одного трильйона третіх |
| 10^15 | давальний | одному квадрильйонові третіх |
| 10^18 | орудний | одним квінтильйоном третіх |
| 2 × 10^15 + 3 × 10^12 + 5 | орудний | двома квадрильйонами трьома трильйонами п'ятьма третіми |

The multipliers follow the existing §105 rules (no exception for 21 or 101); the denominator after a numerator ending in
a scale noun stays the genitive plural (`% 1000 == 0`), after 10^12 + 1 the feminine singular, after a numerator ending
in units the plural of the case. The accusative equals the nominative cardinal pipeline.
