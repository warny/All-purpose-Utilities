# Utils.NumberToString audit closures — 2026-09-23

## NTS-06 — ordinal capability contract

Closed. Concrete ordinal overloads now fail closed when ordinal conversion is unsupported, and an
`IOrdinalLanguageSpecifics` implementation is treated as an effective ordinal capability. Tests
cover unsupported converters, plugin-only ordinal clock hours, partial plugins that decline a
value, the int-only plugin boundary for long values, and plugin-to-XML fallback. A plugin-only
converter now fails closed rather than returning a cardinal when its plugin declines a value.

## NTS-07 — hour-conditioned ClockTime rule selection

Closed. `ClockTimeRule.DisplayHourRange` and the `displayHourRange` XML attribute condition rules
on the candidate rule's projected display hour. Converter construction snapshots the ranges,
validates candidate-specific offsets plus complete/non-overlapping coverage, precompiles formatters,
and creates a 24-by-60 lookup. Runtime conversion remains a direct lookup. Tests cover 12-hour
projection, candidate offsets, gaps, overlaps, special hours, XML parsing, and legacy behavior.

The broader language audit remains open as NTS-08 in `TODO.md`; no unverified linguistic rules were
added merely to advertise support.
