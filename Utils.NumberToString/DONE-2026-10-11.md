# Utils.NumberToString audit closure — 2026-10-11 (NTS-28)

## NTS-28 — compound and large-scale ordinals (closed)

NTS-08 narrowed the ordinal domains to what had been validated and recorded in NTS-28 the families the
declarative last-word pipeline did not build; NTS-27 then repaired the cardinals several guards depended on.
NTS-28 re-audited every family against sources read during the pass and gave each one a final disposition. Each
newly supported family was written as a `.feature` expectation and run red before the change. The detailed
record is the section "NTS-28" of `docs/NTS-08-linguistic-sources.md`.

### A. Machinery used

| Lang. | Mechanism |
|---|---|
| ES | Declarative: `<OrdinalComposition>` (31–99 by 10, 101–999 by 100, then by 1000 and 1 000 000), word rules for 200–900 and *millonésimo*, `<OrdinalScale scales="1..2" multiplierSeparator="">` + `<OrdinalStem>` (*dosmilésimo*), suffix `o`/`a` for those stems; guard widened |
| PT, EL | Declarative: `<OrdinalComposition>` (21–99, 101–999, 1001–1999), PT word rules for 200–900; guards widened |
| GL | Declarative: ordinal-only `<Replacement>`s turn every element but the last into its masculine ordinal (NOMIG: gender on the last element only), word rules for 200–900, 11–19 and *milésimo*; guard widened. `<OrdinalComposition>` was not usable: it agrees every part |
| FI | Declarative: `<OrdinalComposition>` with an empty separator (one word, marker in every part); guard widened in the nominative |
| RU | Existing guard + new protected extension point `OrdinalDomainGuardLanguageSpecifics.TryBuildOrdinal`: the plugin builds the one-word round thousands and millions (genitive combining form + declined *-тысячный/-миллионный*); the composite ordinals stay declarative (ordinal replacement for the bare *миллион*) |
| PL | Existing plugin extended (2000–999 999: thousands cardinal + ordinal tail; round thousands as one word) |
| UK | Existing plugin extended (round thousands, millions and milliards with genitive combining forms) |
| JA, KO, ZH, VN, HI, EU | Guards widened only: the ordinal rule of the sources is general (prefix 第/제/thứ, suffix -वाँ/-garren); the declarative pipeline already formed the values on the NTS-27 cardinal |
| SV, AR | Unchanged (fail-closed) |
| NL | Unchanged: blocked by the new cardinal ticket NTS-31 |

No generic engine primitive was added: the only API addition is the protected virtual `TryBuildOrdinal` of the
public guard base class (a hook for a language plugin; the default builds nothing).

### D. Dutch

The NL cardinal stops at 999 999 (`maxNumber`), with `duizend` and an unused `miljoen` suffix. The long scale is
described by secondary sources only (Onze Taal via DBNL, webwoordenboek.nl); no normative source was found for the
names above *biljard*, for *een miljoen*, nor for *miljoenste*. Dutch long-scale support was therefore **not**
implemented: NTS-31 records the prerequisite, and the NL ordinal guard stays at 999 999 (BLOCKED BY NTS-31).

### E. NTS-30 dependencies

ES ≥ 10^9, RU ≥ 10^9, EU ≥ 10^9, VN values with a whole zero class, FI ≥ 2000 (with a missing source). NTS-30 gained
the Finnish cardinal defects found on the way (`kaksi tuhat`, spaced compounds).
