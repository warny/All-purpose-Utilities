Class LanguageXmlModel

Namespace
Utils.NumberToString
Assembly
Utils.NumberToString.dll

Internal XML model for a language definition. Holds the presence-sensitive groupSize attribute (plus its Specified companion) alongside every other XML member of a language so XmlSerializer can populate it directly. It is projected onto the public LanguageType after inheritance resolution.
