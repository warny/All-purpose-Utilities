ParseFont(Stream, TrueTypeFontParsingOptions)

Parses a TrueType font from a stream.

public static TrueTypeFont ParseFont(Stream s, TrueTypeFontParsingOptions options = null)

Parameters

s Stream

The stream containing the font data.

options TrueTypeFontParsingOptions

Parsing options, or null to use Default.

Returns

TrueTypeFont

An instance of TrueTypeFont.

Remarks

For a seekable s, the font is read starting at its current position (fontStart); every table offset in the SFNT directory is interpreted relative to that position, not to the start of the stream. On return, the stream position is left at fontStart + 12 + numTables * 16 (the end of the table directory): reading table payloads uses bounded, independent views over the stream that do not otherwise move its position. For a non-seekable s, the font is first copied, incrementally and under MaximumFontBytes, into an owned temporary buffer that is always disposed before this method returns (regardless of LeaveOpen, which only governs s itself).

WriteFont(Stream, TrueTypeFontWritingOptions)

Serializes the TrueType font directly to a destination stream.

public virtual void WriteFont(Stream destination, TrueTypeFontWritingOptions options = null)

Parameters

destination Stream

The stream to write the serialized font to.

options TrueTypeFontWritingOptions

Writing options, or null to use Default.

Remarks

Implemented as a thin wrapper over WriteFont(TrueTypeFontWritingOptions): the whole font is still assembled in memory first (so that a validation failure never leaves a partial font in the in-memory buffer), then copied to destination in one write. If destination itself fails partway through that write (an I/O error), it can be left holding a partial, invalid font -- this method only guarantees atomicity for the in-memory layout, not for the destination stream.
