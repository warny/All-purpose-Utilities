Shared productive ordinal formation for the Scandinavian languages (Danish, Norwegian Bokmål, Swedish). Below one hundred the whole number is a single ordinal word (Danish enogtyvende, Norwegian tjueførste, Swedish tjugoförsta); above one hundred only the part below one hundred becomes ordinal and follows the cardinal of the round part (hundrede og første), while an exact round number ordinalizes its last scale word (tusinde, tusende, miljonte).

Remarks

IOrdinalLanguageSpecifics receives no converter, so the cardinal of the round part is rebuilt here from the standard orthography of each language. Only the int range is implemented: larger values are declined and, with no declarative fallback configured, fail closed with NotSupportedException.
