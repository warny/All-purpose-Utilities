Namespace Utils.Fonts.TTF.Parsing

Classes

FontDiagnostic

Describes a single structural anomaly found while parsing a TrueType/OpenType font.

FontParseException

Thrown when a TrueType/OpenType font fails to parse under Strict, or when a resource limit configured on TrueTypeFontParsingOptions is exceeded (which is fatal in both validation modes).

TrueTypeFontParsingOptions

Immutable set of limits and policy switches that govern how ParseFont(ReadOnlySpan<byte>, TrueTypeFontParsingOptions) and its overloads read a font. All limits are explicit, bounded, and validated before the corresponding data is allocated or read, so that a hostile font cannot force unbounded memory use or CPU time.

TrueTypeFontWritingOptions

Immutable set of limits and policy switches that govern how WriteFont() and its stream-based overloads serialize a font.
