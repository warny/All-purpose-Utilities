Remarks

Three constraints are supported, each optional, at least one required: TerminalScales (the scale noun the numeral ends on, decided on its group structure), NumberRange (the count of the amount, optionally taken modulo NumberModulo) and BeforeNoun (the beginning of the noun).

Among the rules of a CurrencyNounConnector that match an amount, the one with the most constraints (Specificity) wins; at equal specificity the first declared wins. Instances are immutable.

Parameters

value string

The connector placed after the numeral and its Separator, e.g. "de" or "d'"; empty for no connector (the numeral, the Separator, then the noun).

nounSeparator string

The text between the connector and the noun, e.g. "" after an elided d'; null for the language's Separator. Ignored when value is empty.

terminalScales IntRange<long>

The scale indices (at least 1) the numeral must end on, or null for no condition.

numberRange IntRange<long>

The counts (non-negative) of the amount the rule applies to, or null for no condition.

numberModulo long?

When set (at least 2), numberRange is tested against the count modulo this value, e.g. 100 for the last two digits; requires numberRange.

beforeNoun IEnumerable<string>

The beginnings of the currency noun (compared ordinally, ignoring case), one of which must begin the noun, or null for no condition. The sequence is copied in order.

Exceptions

ArgumentNullException

value is null.

ArgumentException

value is white space; a range covers no value, or a scale below 1, or a negative count; numberModulo is below 2, set without numberRange, or leaves no residue in the range; an entry of beforeNoun is null, empty or white space; or no constraint is given.
