Gets the first exception thrown by the tracer, or by an engine call the tracer attempted (refused), or null. Once it is set, the operations of the scope are no longer traced; the traced operations are never affected by it.

UndeliveredEvents

Gets the number of events of the scope's operations that were created but never delivered to the tracer, because the bounded list of events awaiting delivery was full (an operation creating many events while the stack was too short to call the tracer) or because the stack was still too short when the operation ended. A dropped event leaves a gap in the Sequence numbers; the resource refusal and the failure of the root treatment that conclude a failed operation are kept. The events a tracer itself discards (a bounded collector, for instance) are not counted here.

public long UndeliveredEvents { get; }
