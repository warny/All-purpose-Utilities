Remarks

Axes. TrustPolicy decides whether DeterministicAttribute declarations count as facts; AggressiveSimplification lifts a closed list of evaluation guarantees on analyzed code; ExceptionPreservation lists the exception categories that must stay observable. None of them implies another, and none makes unknown code (Unknown) or side effects rewritable.

Immutability. The type is an immutable record, validated by its init accessors (so a with expression is validated too). A simplifier receives it at construction (new ExpressionSimplifier { Options = … }) and cannot change it afterwards, so nested, re-entrant and concurrent calls on an instance apply the same policy; use two instances for two policies. There is no ambient or static policy.

Properties

AggressiveSimplification

Gets whether the rules may relax the guarantees that only matter to identity and timing on analyzed code. Defaults to false.

public bool AggressiveSimplification { get; init; }

Property Value

bool

Remarks

When set, a future rule may drop, merge, repeat or move an evaluation that allocates (the identity and number of the objects it creates are not preserved), and merge, repeat or move a nondeterministic evaluation that has no side effect (a clock read: two reads may become one), provided it raises no exception category that is still preserved.

It never relaxes: side effects; unknown code (it does not turn Unknown into a verified classification, nor executes user code during simplification); the preserved exception categories (ExceptionPreservation alone decides them); declarations (TrustPolicy alone decides them); the order of a mutable-state read relative to the side effects around it; the absence of new exceptions; the IEEE and domain contract of the simplifier.

Default

Gets the conservative defaults: Verified, no aggressive simplification, every exception category preserved.

public static ExpressionSimplifierOptions Default { get; }

ExpressionSimplifierOptions

ExceptionPreservation

Gets the exception categories whose observation must be preserved. Defaults to All.

public ExpressionExceptionPreservation ExceptionPreservation { get; init; }

Property Value

ExpressionExceptionPreservation

Remarks

A category left out may, under the explicit conditions of a future rule, be dropped or observed in another order relative to other movable evaluations. It never makes unknown code, side effects, allocations or nondeterminism eliminable, and never allows a rewrite to introduce an exception or to raise one during simplification.

Exceptions

ArgumentOutOfRangeException

The value has a flag outside All.

TrustPolicy

Gets whether DeterministicAttribute declarations count as facts. Defaults to Verified: a classification that relies on a declaration is treated as unknown code.

public ExpressionTrustPolicy TrustPolicy { get; init; }

Property Value

ExpressionTrustPolicy

Remarks

TrustDeclarations trusts the declared promise only (deterministic, no ambient state, no side effect): a declared method may still throw (MayThrowUserCode), allocate and read the state of its arguments, and code that is neither declared nor verified stays unknown. It does not enable AggressiveSimplification.

Exceptions

ArgumentOutOfRangeException

The value is not a defined ExpressionTrustPolicy.
