Properties

ResourceLimits

Gets the resource limits of this instance (ETC R1a-Security). They apply when this instance starts an operation: the first TransformCore(Expression) or ReplaceArguments(Expression, ParameterExpression[], Expression[]) call made while no expression operation runs on the thread validates its input against MaxDepth and MaxNodes and bounds the whole call by the visit budgets. Inside a running operation, the active limits are kept: an instance can never loosen them.

protected ExpressionResourceLimits ResourceLimits { get; }

Property Value

ExpressionResourceLimits

Remarks

Only the engine methods of this class are protected. A subclass whose public Transform(Expression) never calls TransformCore(Expression) (or ReplaceArguments(Expression, ParameterExpression[], Expression[])) runs its own code outside these limits.

Remarks

Since ETC R1a (compatibility entry C-02), New, NewArrayInit, NewArrayBounds, TypeIs, TypeEqual, Block and Loop follow an arity contract: an empty list returns the node unchanged (it is the child list a transformer passes for a node it did not traverse, or there is no child to replace), a list of the node's arity rebuilds it with its metadata (members, variables, result type, labels), and any other length throws ArgumentException. A rethrow (a Throw without operand) is returned unchanged. Other families keep their historical behavior.

TransformCore(Expression)

Applies transformation rules to a given expression, returning a (potentially) modified expression. This method checks for known signatures (via ExpressionSignatureAttribute-annotated methods) and if a match is found, invokes the corresponding transformation function. If no signature method matches, it calls FinalizeExpression(Expression, Expression[]) by default. This is the internal recursive engine invoked by a subclass's public Transform(Expression) override; it never re-enters Transform(Expression) itself, so recursive continuations here cannot accidentally reset a transformer's per-call state.

protected Expression TransformCore(Expression e)

Parameters

e Expression

The expression to transform.

Returns

Expression

A possibly rewritten expression.

Remarks

Resource safety (ETC R1a-Security): when no expression operation runs on the thread, this call starts one with ResourceLimits: e is validated first, and the whole call, including every recursion and nested comparison, is bounded by the visit budgets. Every call checks the execution stack before recursing; each node processed is counted once, by Utils.Expressions.ExpressionTransformer.TransformPrepared(Utils.Expressions.ExpressionTransformer.TransformContext).

Exceptions

ExpressionResourceLimitException

A resource limit was exceeded, or the stack ran out.
