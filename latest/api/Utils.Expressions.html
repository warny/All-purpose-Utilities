Namespace Utils.Expressions

Classes

BlockExpressionBuilder

A helper class that builds expression blocks while minimizing the number of declared variables.

CompileException

Represents the base class for compile-time exceptions that occur during expression compilation in the Utils.Expressions namespace.

ConstantNumericAttribute

A specialized attribute that indicates the expected parameter is a ConstantExpression holding a numeric value, optionally restricted to a specific set of allowed numeric values.

DeterministicAttribute

Declares that a method is deterministic and free of observable side effects (S5 P18 Architecture A). The declaration is read by ExpressionBehaviorAnalysis; it is a promise made by the author of the method, never a verified property of its body.

ExpressionBehaviorAnalysis

Classifies what evaluating an expression tree may do besides producing its value: whether it is deterministic, reads mutable state, has side effects, allocates, and which kinds of exceptions it may throw, with the parts of the classification that could not be analyzed or that rely on user declarations (S5 P18 Architecture A).

ExpressionCallSignatureAttribute

Marks a method as matching only method-call expressions that invoke a specific function name on a specific type. This is a specialized ExpressionSignatureAttribute for calls.

ExpressionCompilerContext

Represents a dynamic symbol context shared by expression compilers.

ExpressionEx

Provides helper methods for building and manipulating expression trees.

ExpressionOptimiser

Provides a standard optimization pass over expression trees.

ExpressionResourceLimitException

Thrown when an expression-tree operation exceeds one of its ExpressionResourceLimits, or when the remaining execution stack is insufficient to continue it safely.

ExpressionResourceLimits

Immutable resource limits applied by the expression-tree engine (ExpressionTransformer, ExpressionSimplifier, ExpressionComparer) to one public operation.

ExpressionSignatureAttribute

Marks a method or parameter as having a signature requirement for a certain ExpressionType. When used on a method, the method is considered for transformation if its attribute matches the current node type. When used on a parameter, it further restricts which sub-expressions are permissible.

ExpressionSimplifierOptions

The rewrite policy of an ExpressionSimplifier (S5 P18 Architecture B): three independent axes that a later stage (Architecture C) will let the rules consult through the behavior permissions. No rule consults them yet: every value gives the same simplification results, the same user calls and the same comparer answers as the default.

ExpressionTraceCollector

A tracer that stores the events of the operations it traces, up to a fixed number (see Begin(IExpressionTransformTracer, ExpressionTraceDetail)).

ExpressionTraceCycleAnalyzer

Looks for non-terminating rewriting in trace events (see ExpressionTraceCollector): forms re-entered inside their own treatment, periodic rule sequences along the deepest recursion, and rules that never reduce the forms. A diagnostic tool, separate from the engine: it never transforms, simplifies or canonicalizes anything, and never changes how the engine behaves.

ExpressionTraceCycleOptions

Options of ExpressionTraceCycleAnalyzer. This type only holds data.

ExpressionTraceCycleReport

The result of Analyze(IReadOnlyList<ExpressionTransformEvent>, ExpressionTraceCycleOptions?). This type only holds data.

ExpressionTraceExportOptions

Options of ExpressionTraceExporter. This type only holds data.

ExpressionTraceExporter

Exports trace events (see ExpressionTraceCollector) as an indented text, one line per event nested by treatment depth, or as JSON. Exporting is an explicit step, outside the engine: nothing is rendered while tracing.

ExpressionTraceFormatter

Renders expression trees for diagnostics (trace exports) without running user code: bounded in depth and length, and blind to the content of extension nodes.

ExpressionTracePeriod

A rule sequence that repeats along the deepest chain of nested treatments. This type only holds data.

ExpressionTraceRecurrence

A form transformed again while it is already being transformed by an enclosing treatment: the recursion re-entered the same problem. This type only holds data.

ExpressionTraceRuleBalance

How the applications of one rule changed the size of the forms. This type only holds data.

ExpressionTraceScope

A tracing scope opened by Begin(IExpressionTransformTracer, ExpressionTraceDetail): dispose it to stop tracing.

ExpressionTransformRuleInfo

Identifies one rule of a transformer (a method marked with ExpressionSignatureAttribute) in trace events. This type only holds data.

ExpressionTransformTracing

Opens tracing scopes for the expression transformation engine: every operation of the engine (simplification, comparison, transformation, substitution) started while a scope is active on the current execution context reports its events to the scope's tracer.

ExpressionTransformer

Provides an abstract base class to transform or rewrite LINQ expression trees. Subclasses may override the transformation logic for specific expression signatures.

ExpressionUtils

Provides utility helpers for analysing and comparing expression trees.

FindTypeException

Thrown when a type cannot be found during a type resolution process.

FormattedPart

Represents a formatted part of an interpolated string, containing an expression and optional format/alignment specifications.

InterpolatedStringParser

Parses an interpolated string into its constituent parts, which can be either literals or formatted expressions.

LiteralPart

Represents a literal (non-interpolated) part of a string.

Parenthesis

Describes a set of parenthesis tokens used by the expression parser.

ParseDuplicateParameterNameException

ParseUnfindTypeException

ParseUnmatchException

ParseWrongSymbolException

ParserOptions

Provides configuration settings and default mappings for parsing expressions, including operator priorities, numeric type levels, default type keywords, and numeric suffix mappings.

ReturnTypeAttribute

A specialized attribute that indicates the matched expression's return type must be assignable to a specified type. Useful for restricting the type of an operand beyond its ExpressionType.

Enums

ExpressionBehaviors

What evaluating an expression may do besides producing its value, as classified by ExpressionBehaviorAnalysis (S5 P18 Architecture A). Every flag but ReliesOnDeclaration is a "may" fact: an absent flag is a guarantee of the analysis, a present flag only says that the behavior could not be excluded.

ExpressionExceptionPreservation

The exception categories of ExpressionBehaviors whose observation a simplification must preserve (S5 P18 Architecture B). A set flag means "preserve": a rewrite never drops such an exception, nor changes its order relative to the other observable events of the evaluation. Used by ExceptionPreservation.

ExpressionResourceLimitKind

The resource dimension whose limit an expression-tree operation exceeded.

ExpressionRuleRejection

Why a candidate rule produced no result (RuleRejected).

ExpressionTraceDetail

The level of detail of a tracing scope.

ExpressionTraceLoopKind

The shape of a periodic rule sequence found by ExpressionTraceCycleAnalyzer.

ExpressionTraceRetention

Which events an ExpressionTraceCollector keeps once it is full.

ExpressionTraceScopeKind

The lexical scope of a ScopeEnter or ScopeExit event.

ExpressionTransformEventKind

The kind of an ExpressionTransformEvent.

ExpressionTransformOutcome

What produced the result of a treatment (TransformExit) or of a finalization.

ExpressionTrustPolicy

How far a simplification policy may rely on the classification of ExpressionBehaviorAnalysis (S5 P18 Architecture A, exposed by Architecture B as TrustPolicy). Not consumed by any rule yet: the simplifier keeps the strict gate of Utils.Expressions.ExpressionEffectAnalysis.
