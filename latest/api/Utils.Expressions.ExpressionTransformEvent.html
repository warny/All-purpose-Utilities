Remarks

Hierarchy. A traced operation is a session (SessionId). Every TransformCore call in it is a treatment with its own OperationId; ParentOperationId is the treatment it runs in (the parent node's treatment, whether the node is a child being prepared or the result of a rule that transforms again), and Depth the number of enclosing treatments. Nested comparisons and nested public calls made during the operation belong to the same session, so the whole recursion can be rebuilt from the events.

Expressions. Input and Output are references to the engine's trees, never copies or renderings; an event keeps them alive as long as it is stored. NodeType is only read from framework nodes: it is null for an extension node, whose members the engine never reads (ETC R4).
