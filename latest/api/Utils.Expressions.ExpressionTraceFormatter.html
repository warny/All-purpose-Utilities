Remarks

Unlike ToString(), the rendering never calls ToString() on a constant of a non-primitive type (shown as <TypeName>), and never reads a member of an extension node (shown as <extension ClassName>): only type tests and the non-virtual GetType() are used on it (ETC R4). Framework node families are rendered in a compact C#-like syntax; the control-flow families (blocks, loops, try, switch, goto, labels) are summarized.

The rendering is a diagnostic aid, not a parser input: parameters are shown by name (unnamed ones as $0, $1, … in order of appearance), so two distinct parameters with the same name look alike.
