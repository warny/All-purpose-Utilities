Remarks

A public operation is the outermost call into the engine on a thread (for example Simplify, Equals, GetHashCode, or the first ExpressionTransformer engine call of a custom transformer). Before any work, its input is validated against MaxDepth and MaxNodes; during the work, the transformation and structural visits it performs are counted against MaxTransformVisits and MaxStructuralVisits. Every excess ends with an ExpressionResourceLimitException.

A public call made while another one is running on the same thread (from a rule, or from user code such as a constant's Equals(object)) joins the running operation: it validates its own input and may tighten the limits for its own duration, but it never loosens them and never resets the counters.

Unlimited (or any limit set to MaxValue/MaxValue) disables the corresponding check for trusted inputs. The execution-stack guard is never disabled: a recursion that would exhaust the stack still ends with an ExpressionResourceLimitException of kind Stack.

The visit budgets bound the measured engine work; they do not bound time or memory directly. One transformation visit costs roughly 1–4 µs and 1–6 KB of allocations on the measured workloads, so the default budget may still allocate several gigabytes cumulatively before it is exhausted.
