Remarks

The split is numeric, never textual: each part goes through the complete ordinal pipeline again (ordinal plugin, exceptions, other compositions, OrdinalScaleRule, the cardinal-based transformation) with the caller's variants, so both parts agree. Raw adjustment, end triggers and language finalization run once on the composed result.

A value whose head or tail is zero is not composed and continues through the rest of the pipeline. Both parts are strictly smaller than the value, so the recursion always terminates. Whole-number ordinal exceptions keep precedence.

Parameters

For string

The values covered, in the range syntax of ParseRangeExpression(string) (e.g. "100001..100009"). Every value must be at least 1; the ranges of two rules must not overlap.

Divisor long

The divisor separating head and tail; must be at least 2.

Separator string

The text between the two ordinals; may be empty for a soldered form.
