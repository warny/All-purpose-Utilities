Opens tracing scopes for the expression transformation engine: every operation of the engine (simplification, comparison, transformation, substitution) started while a scope is active on the current execution context reports its events to the scope's tracer.

Remarks

Isolation. A scope is ambient per execution context (AsyncLocal<T>): it flows into the tasks and continuations started inside it, never into concurrent operations started elsewhere, and a scope opened inside another one replaces it until it is disposed. No tracer is ever stored on a transformer instance, so a shared simplifier traces only the calls made inside a scope.

Capture. The scope is read once, when an operation starts on a thread where no expression operation runs; the whole operation, including its nested comparisons, nested public calls and re-entrant rules, reports to that tracer. Opening or disposing a scope while an operation runs (from a rule or a tracer) only affects the next operations.

Cost. Without any open scope in the process, starting an operation reads one static counter and the engine takes its usual path: no event, session or rendering is created.
